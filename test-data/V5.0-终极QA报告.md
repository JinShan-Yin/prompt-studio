## 二、六个套件结果

### 套件一：V4.0 核心资产（双层高亮与快照）——**FAIL**
| 断言 | 结果 | 真实数据 |
|---|---|---|
| 50 行 / 50 变量 / 垂直滚动条 | **FAIL** | textarea scrollHeight=clientHeight=1120（auto-height + overflow:hidden，无滚动条） |
| textarea.scrollTop=150，mirrorDiv.scrollTop=150 | **FAIL** | textarea.scrollTop=0、mirror.scrollTop=0（无滚动条可滚） |
| 强制加 max-height/overflow 后滚动同步诊断 | **FAIL（潜在缺陷）** | 强制后 scrollHeight=1120/clientHeight=298、textarea.scrollTop=150，但 mirror.scrollTop=0（mirror 高度=全文高度，未随 textarea 裁剪滚动） |
| 切 Tab2 再切回 Tab1，高度重撑/几何重合 | PASS | taHeight=1122px、mirrorHeight=1122px、rectDiff top/left/height=0 |
| 生成快照并入库 | PASS | snapshotId=snap-6b2f60e1，列表 count=1 |
| Tab4 下载 TXT，/api/gate/export 返回 200 | PASS | HTTP 200，Content-Type: text/plain; charset=utf-8，Cache-Control: no-store... |

**FAIL 原因**：编辑框采用“自动撑高 + overflow:hidden”设计，长文本不会产生任务要求的垂直滚动条；因此 scrollTop=150 同步断言无法成立。强制制造滚动条后 mirror 不跟随，属潜在高亮错位缺陷（若未来给编辑框加 max-height 会立即暴露）。

### 套件四：公共项目只读与抓包绕过防御——**FAIL**
| 断言 | 结果 | 真实数据 |
|---|---|---|
| SQL 查 global 公共项目 | PASS | proj-b4199dd1（QA_PUBLIC_155501），is_public=1，scope=global |
| 普通用户 UI 只读 | PASS | window.isPublicProject=true、textarea.readOnly=true、生成按钮 disabled、只读徽标可见 |
| 绕过：`POST /api/snapshots/create`（仅 project_id，按任务原文 Payload） | **FAIL** | 返回 **HTTP 400** `{"success":false,"error":"layers 必须是数组"}`，而非 403 |
| 补测：同接口带合法 layers | PASS | HTTP 403 `{"success":false,"error":"公共项目禁止修改"}` |
| 绕过：context/save / kb/save / projects/delete | PASS | 均 HTTP 403 `{"success":false,"error":"公共项目禁止修改"}` |

**FAIL 原因**：`/api/snapshots/create` 先做 body 校验（layers 必须是数组）再做项目权限校验，导致任务给出的最小越权 Payload 返回 400 而非 403；无实际写入。另：错误文案为“公共项目禁止修改”，与任务要求的“无权修改公共项目”不一致。

## 四、真实数据汇总（SQL / HTTP 原始值）

- 并发白嫖：5 并发状态码 `[200,200,403,403,200]`；SQL `trial_count = 3`；第 6 次 HTTP 403 `{"code":"TRIAL_EXHAUSTED","error":"免费试用额度已用完（3/3），请配置自己的 API Key"}`。

- API 绕过拦截（真实 403 JSON）：
  - context/save、kb/save、projects/delete：`{"success":false,"error":"公共项目禁止修改"}`（HTTP 403）
  - snapshots/create（无 layers）：`{"success":false,"error":"layers 必须是数组"}`（HTTP 400，见 F2）
  - snapshots/create（带 layers）：`{"success":false,"error":"公共项目禁止修改"}`（HTTP 403）
- SQL 复核：公共项目 context_json="{}"、snapshots=0、kb=0；A 项目 KB=3；克隆项目删除 1 条后原项目仍 3；串行项目删除后 KB=0。
