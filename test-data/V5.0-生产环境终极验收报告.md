### F3：黑匣子审计日志（level / IP / 管理面板 / 代管 Warn）
- 数据库幂等迁移：`audit_logs` 新增 `level TEXT DEFAULT 'Info'`、`ip TEXT DEFAULT ''`，历史 30 条回填 Info。
- `requestContext` 记录请求 IP（`req.ip`/socket 地址）；`logAction` 自动分级：
  - 删除/重置/导入等高危动作 → **Danger**
  - 超管/团管修改**他人项目/知识库/快照**（代管）→ **Warn**
  - 其余 → **Info**
- `GET /api/admin/audit-logs` 返回 `level/ip/username`，支持 `?level=Info|Warn|Danger` 过滤；仅超管可访问，只读无删除/修改接口。
- 管理控制台新增「📜 审计日志」入口（仅超管可见）→ 全屏面板（挂载 `<body>`）：
  - 表格列：时间 / 级别 / 用户 / 动作 / 对象 / IP / 详情
  - Info 绿、Warn 黄、Danger 红标签 + 行底色；级别筛选、刷新、Esc 关闭
- **复测真实数据**：
  - `audit_logs` 列：`[id,user_id,action,target_type,target_id,detail,created_at,level,ip]` ✅
  - admin 代管修改用户 D 项目语境 → `level=Warn, ip=127.0.0.1, action=context_save` ✅
  - admin 删除演练项目 → `level=Danger, ip=127.0.0.1, action=project_delete` ✅
  - API 过滤 `level=Warn` 正常返回、含 IP ✅
  - 普通用户访问审计 API → 403「仅超级管理员可查看审计日志」✅
  - 面板 UI：入口仅超管可见；Warn/Danger 颜色区分；IP 展示 127.0.0.1；筛选 Warn 仅剩 Warn 行 ✅
- **F3 后端 7/7 PASS、UI 6/6 PASS、普通用户权限 4/4 PASS。**
